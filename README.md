# scoop-noqtis

[Scoop](https://scoop.sh) bucket for [NOQTIS](https://github.com/rootcoder007/noqtis), the post-quantum signing and sealing tool.

```powershell
scoop bucket add noqtis https://github.com/rootcoder007/scoop-noqtis
scoop install noqtis/noqtis
```

The manifest installs the release zip for x64 or arm64, checked against its SHA-256, and puts `noqtis` on PATH. `scoop update noqtis` follows new releases.
